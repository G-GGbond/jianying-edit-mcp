# 口播配音：脚本 → 一键生成

从一份带时间轴的口播脚本，一条命令生成配音、压到时间槽、拼成整轨、并可直出 EDL。

---

## 一条命令

```powershell
jianying-edit narrate --script 口播脚本.json --out .\配音 --edl .\配音\edl.json
```

产物：

```
配音/
├─ raw/              每句原始合成（保留，方便对比）
├─ fitted/           压到时间槽后的每句
├─ narration.wav     拼接 + 响度标准化的整轨（可直接给 jy_build）
└─ edl.json          解说轨 + 字幕轨，喂给 jy_build 就能出片
```

接着出片：

```powershell
jianying-edit build --edl .\配音\edl.json --out .\工程
jianying-edit render --draft .\工程\<名字>_剪映可读 --out .\成片.mp4
```

## 口播脚本格式

```json
{
  "name": "展会介绍",
  "canvas": { "width": 1920, "height": 1080, "fps": 30 },

  "voice": {
    "backend": "voicestudio",
    "url": "http://192.168.1.50:3900",
    "refAudio": "D:/我的声音.wav",
    "refText": "这是我录音的原文，十个字以上效果更好",
    "engine": "omnivoice-gguf"
  },
  "defaultDirection": "沉稳有力的男声，语速适中，像纪录片旁白",
  "autoRateFit": true,

  "lines": [
    { "start": 0.0,  "end": 4.0,  "text": "2026 上海，光伏与智慧能源展。", "direction": "开场明亮，有精神" },
    { "start": 4.0,  "end": 7.7,  "text": "这里是飞凌嵌入式 FORLINX 展台。" },
    { "start": 7.7,  "end": 11.4, "text": "整墙核心板，覆盖主流平台。", "direction": "介绍产品，语速稍快" }
  ]
}
```

字段说明：

| 字段 | 作用 |
|---|---|
| `voice.backend` | `edge`（默认，免费联网）/ `voicestudio`（本地或 GPU 机器）/ `sapi`（离线兜底） |
| `voice.url` | VoiceStudio 地址。**GPU 那台机器就是 `http://它的IP:3900`** |
| `voice.refAudio` + `refText` | 音色克隆：给一段参考录音，克隆出同样音色 |
| `voice.engine` | 引擎名，CPU 机器建议 `omnivoice-gguf` |
| `defaultDirection` | 全局语气描述 |
| `lines[].direction` | 单句语气，覆盖全局 |
| `autoRateFit` | 文案超时自动让服务端改写压缩 |
| `lines[].start/end` | 该句占用画面的时间槽（秒） |

## 语气怎么控制

**用自然语言写，不用记参数。**

```json
"defaultDirection": "沉稳有力的男声，语速适中，像纪录片旁白"
```

内部流程：

```
你的描述  →  POST /tools/direction  →  instruct 提示词  →  POST /generate
             （VoiceStudio 解析）        （结构化语气）      （实际合成）
```

可以写的维度（VoiceStudio 的 director 会解析）：

| 维度 | 例子 |
|---|---|
| 音色特征 | 低沉、清亮、有磁性、年轻 |
| 情绪 | 振奋、克制、温暖、专业 |
| 语速 | 语速偏慢、稍快、沉稳 |
| 场景 | 像新闻播报、像纪录片旁白、像产品发布会 |

单句可以覆盖：

```json
{ "start": 11.4, "end": 15.6, "text": "重点看这套方案……", "direction": "放慢，强调" }
```

`narrate` 会把解析结果写进返回的 `instruct` 字段，方便你核对到底转换成了什么。

## 自定义音色：两条路

### 路 A：音色克隆（推荐）

准备一段 10 秒以上的干净录音（自己念的、或你认可的声音），配上它的文字：

```json
"voice": {
  "refAudio": "D:/ref/我的声音.wav",
  "refText": "这是我这段录音里说的原话，十个字以上"
}
```

然后每一句都会用这个音色念。

**参考录音要求**（VoiceStudio 侧）：
- 安静环境、无背景音乐
- 单人说话，10 秒以上
- `refText` 必须是录音里真实的文字，越长越准

### 路 B：音色设计（不用录音）

只写描述，不要 `refAudio`：

```json
"voice": { "backend": "voicestudio" },
"defaultDirection": "四十岁男性，声音低沉有磁性，语速偏慢，像企业宣传片旁白"
```

## 在 GPU 那台机器上怎么准备

你的测试机有 GPU，把它当配音服务器：

1. **装 VoiceStudio**（[下载页](https://github.com/debpalash/VoiceStudio/releases/latest)）
   - Windows 装 `VoiceStudio-0.5.8-win-x64.exe`
   - GPU 机器用默认引擎 `omnivoice`（需 6GB 显存以上）
2. **确认服务在跑**：浏览器打开 `http://127.0.0.1:3900` 能看到界面
3. **开启局域网访问**：
   - 应用内 Settings → 网络共享（Share）打开
   - 或设环境变量 `OMNIVOICE_API_KEY=<一个密码>`，调用时带上
4. **Windows 防火墙放行 3900 端口**
5. 在跑 `narrate` 的机器上把 `voice.url` 改成 `http://<GPU机器IP>:3900`

> 回环地址（127.0.0.1）默认免认证；**跨机器就必须开共享或配 API key**，
> 这是它自己的安全设计，不是我加的。

验证连通：

```powershell
jianying-edit narrate --script 口播脚本.json --out .\试音 --backend voicestudio --url http://192.168.1.50:3900
```

连不上会明确报错并提示检查什么。

## 时间槽对不上怎么办

`narrate` 会给出每句的实测数据，看 `problems` 字段：

```json
"problems": [
  "第 4 句超时：原长 7.224s，槽 4.2s，最多只能压到 1.5 倍；建议删字或加时长"
]
```

三种解法，按推荐顺序：

| 解 | 做法 | 代价 |
|---|---|---|
| **改稿** | 按 5 字/秒反推，把超长句砍到 `slot × 5` 字以内 | 要重写文案，但效果最自然 |
| **加时长** | 把整片从 30s 延到 37s（或把该镜头拉长） | 片子变长 |
| **自动压缩** | 脚本里设 `"autoRateFit": true`，让 VoiceStudio 的 LLM 改写 | 依赖服务端模型，改写质量不一定合你意 |

汉字舒适区是 **4~5.5 字/秒**。超过 6.5 一定听起来赶。

## 参数对照（不用改脚本时直接传命令行）

```powershell
jianying-edit narrate `
  --script 稿.json --out 输出目录 `
  --backend voicestudio `
  --url http://192.168.1.50:3900 `
  --engine omnivoice-gguf `
  --ref-audio D:\ref\我的声音.wav `
  --ref-text "参考录音的原文" `
  --direction "沉稳男声，纪录片旁白感" `
  --auto-rate-fit `
  --edl 输出\edl.json --subtitles
```

`--no-normalize` 关闭数字/型号读法规范化（默认 `2026→二零二六`、`T536→T 五三六`、`FCU→F C U`）。

## 已知限制

| 限制 | 说明 |
|---|---|
| 语速是事后变速 | 超过 1.5 倍会失真；真正解决办法是改稿或加时长 |
| 语气解析依赖服务端 | `/tools/direction` 不可用时退回原文直传，效果打折 |
| 文案压缩依赖 LLM | `/tools/rate-fit` 需要服务端配了 LLM provider，否则跳过 |
| CPU 上很慢 | VoiceStudio 文档原话 "latency-tolerable"，30 秒音频可能要等几分钟 |
| 跨机器要认证 | 必须开共享或配 API key，否则 403 |
